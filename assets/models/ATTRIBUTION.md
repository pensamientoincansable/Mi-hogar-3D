# Model asset notices

All model files in this directory are distributed under **CC0 1.0 Universal**. They are stored locally so Mi Hogar 3D also works on GitHub Pages without a runtime CDN.

## Furniture

- **Furniture Kit** by [Kenney](https://kenney.nl/assets/furniture-kit)
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Local format: embedded GLB
- Files used: bed, sofa, table, chair, floor/table lamps, television cabinet, refrigerator, stove, toilet, bathtub, bookcase, rug, potted plant, mirror, teddy bear, ottoman, coffee table and garden bench.

## Nature

- **Ultimate Stylized Nature Pack** by [Quaternius](https://quaternius.com/packs/ultimatestylizednature.html)
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Local format: FBX; heavyweight source textures are intentionally replaced at runtime with the project's lightweight procedural PBR materials.
- Files used: four deciduous tree variants, pine, birch, maple, palm, bushes, flowering bush, plant and flower clump.

Attribution is not required by CC0, but the original artists are credited here with thanks.
